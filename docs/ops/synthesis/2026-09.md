## What Compounded?

### Wins & Breakthroughs

- **The drafts came back, unprompted, and shipped in three days.** #112 (*The Alignment System*) and #114 (*The Case for Self-Work as Service*) had been content-idle since 06-03/06-04. They resumed 09-18, were marked ready for review 09-18/09-19, and merged 09-21. That ended a fifteen-week run of no product merges. The "awaiting reader feedback" framing was never the real blocker: the 09-20 heartbeat called it spent, and it has gone with the merges.
- **Navigation followed publication immediately.** #142 (home-page cards, breadcrumbs, prev/next, an "All Modules" directory) landed 09-23, two days after the modules, so readers can actually reach all three.
- **The backlog pass turned into two real closures.** August's bet 1 (hygiene pass) sat unstarted for two weeks, then converted in the final week into #143 (closes #22: separate PDF/EPUB targets, fail on swallowed Pandoc errors, empty source sets and missing outputs) and #144 (closes #87: 56 Vitest tests plus four Playwright tests and a `test_site` CI job). Both merged 09-29 after ~2.6–2.9 days. The hygiene bet delivered value, but as implementation work rather than triage.
- **The weekly files got more trustworthy.** #137/#138 documented that Board Movement is state-only, that `Current WIP` equals the number of In Progress items, and that off-path moves go under **Other Moves**; #139 corrected the one file that had broken the rule. The routine prompt was reconciled with the template by 09-27.

### Process Improvements

- **The 3/2 reading rule worked as designed.** Under the new counting convention, the 09-20 and 09-27 heartbeats reported WIP at 3/2 rather than hiding the drafts beside the count. That made the over-cap state visible the week it happened, which is what ADR 0001 intends the cap to do.

## What Didn't Work?

### Failed Experiments

- **The hygiene pass as a stand-alone item.** It held a Now slot from 09-06, produced nothing for two weeks, and met the demotion test set on 09-13 (09-20 heartbeat). It was never demoted; the slot was instead absorbed by the pass's own spin-outs. The seven remaining open issues (#17, #18, #24, #28, #36, #37, #52) were not triaged, and the most recent touch among them is still #37 at 2026-05-29.
- **Publishing before the accessibility checklist.** Neither new module has a recorded `docs/policies/ACCESSIBILITY_CHECKLIST.md` pass, although the policy requires one before publishing. #112 did carry real accessibility fixes (opaque territory labels at 5.6:1–8.9:1 contrast, expanded aria-labels and alt text), but nothing was recorded.

### Lessons Learned

- **A WIP dispute cost more than the thing it disputed.** #136 took ~4.2 days to merge, and a follow-up PR (#139) was needed, because the wrong `0/2` was argued for in review from two older heartbeat files without checking ADR 0001. #138 now marks those files non-precedent. Check the ADR before citing a prior file as authority.
- **Infra riding inside a content PR is a cost the repo chose to accept.** `scripts/export.sh`, `docs/policies/pandoc.yaml`, a CI package and compiled printables all landed inside #112. It was merged rather than split, so generated PDF/EPUB under version control is now the precedent. The consequence is uneven coverage: `the-case-for-self-work-as-service` has no printables.
